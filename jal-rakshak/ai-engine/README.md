# AI Engine — JAL-RAKSHAK

The AI Engine houses predictive and analytical modules:
1. **Anomaly Detection**: Identifies pressure drops, burst pipelines, and contamination spikes.
2. **Demand Forecasting**: Predicts hourly and seasonal water demands.
3. **Shortage Prediction**: Forecasts reservoir exhaustion horizons.
4. **Sensor Fusion**: Reconciles noise across flow, pressure, pH, and turbidity sensors.
